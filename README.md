# 🇧🇷 Brazilian E-Commerce SQL Business Analysis

## 📌 Project Overview

This project explores the Brazilian E-Commerce Public Dataset (Olist) using MySQL.

The goal was to analyse a real-world e-commerce database and solve business problems using SQL. Instead of writing isolated queries, this project focuses on extracting meaningful business insights from relational data.

---

## 📊 Dataset

- Dataset: Brazilian E-Commerce Public Dataset by Olist
- Source: Kaggle
- Records: 99,000+ Orders
- Database: MySQL

---

## 🗂 Database Tables

- olist_orders
- olist_customers
- olist_order_items
- olist_order_payments
- olist_products
- olist_sellers
- olist_order_reviews

---

## 📈 Business Problems Solved

### Revenue Analysis
- Monthly Revenue Analysis
- Average Order Value (AOV)
- Revenue by Product Category
- Revenue by State
- Revenue by Payment Method

### Customer Analysis
- Customer Churn Analysis
- Repeat Customer Analysis
- Customer Lifetime Value
- Customer Spending Analysis

### Delivery Analysis
- Average Delivery Time
- Late Deliveries
- On-Time Delivery Rate
- Delivery Performance by State

### Customer Satisfaction
- Review Score Analysis
- Product Rating Analysis
- Seller Rating Analysis
- Low Rated Categories

### Seller Performance
- Top Revenue Sellers
- Order Volume
- Product Sales
- Freight Revenue

### Product Performance
- Best Selling Categories
- Highest Revenue Categories
- Product Pricing Analysis

### Regional Analysis
- Revenue by State
- Revenue by City
- Customer Distribution

### Executive KPI Dashboard
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Average Review Score

---

## 🛠 SQL Concepts Used
